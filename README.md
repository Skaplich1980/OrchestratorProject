# 🤖 Python Project Orchestrator

Мульти-агентный CLI-оркестратор для автономной автоматизации задач в Python-проектах. Система самостоятельно анализирует цель, разбивает её на атомарные шаги, выполняет правки кода через Agnes Code CLI и строго проверяет результат.

> 📘 **Как пользоваться программой — см. [USAGE.md](USAGE.md).**

## ⚙️ Архитектура

1. **Model Resolver (Ядро маршрутизации):** При старте (или раз в неделю) сканирует доступные бесплатные модели на подключенных роутерах. Использует «умный поиск» по ключевым словам (например, `qwen3`, `deepseek-v3`) и кеширует результат в `models_cache.json`.
2. **Планировщик (Planner):** Получает от Model Resolver приоритетную очередь моделей. Генерирует строгий JSON-план шагов. При ошибке (Rate Limit, Timeout) мгновенно переключается на следующую модель/роутер в очереди без прерывания работы.
3. **Исполнитель (Executor):** Вызывает **Agnes Code CLI** для выполнения шага. Гарантирует безопасность: автоматический бэкап целевых файлов перед правкой и инъекция `.agneshints` с правилами проекта.
4. **Ревьюер (Reviewer):** Анализирует `stdout`, `stderr` и код возврата от Agnes. Использует ту же лучшую доступную модель, что и планировщик. Если шаг выполнен некорректно, оркестратор инициирует перепланирование или останавливается с явной причиной.
