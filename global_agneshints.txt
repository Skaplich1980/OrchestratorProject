# ГЛОБАЛЬНЫЕ ПРАВИЛА ДЛЯ AGNES CODE (КРИТИЧЕСКИ ВАЖНО)
Следуй этим правилам неукоснительно при выполнении любого шага:

1. ЗАПРЕТ НА УДАЛЕНИЕ: НИКОГДА не удаляй существующие функции, классы, импорты или строки с комментариями, если это не указано явно и однозначно в задаче.
2. СОХРАНЕНИЕ СИГНАТУР: Не меняй имена и аргументы существующих функций без крайней необходимости.
3. ПРОВЕРКА ПЕРЕД УДАЛЕНИЕМ: Перед удалением любого фрагмента кода мысленно убедись, что он нигде не вызывается в проекте.
4. МИНИМАЛЬНЫЕ ПРАВКИ: Делай только минимально необходимые изменения для выполнения текущей подзадачи. Не рефактори "заодно".
5. ТИПИЗАЦИЯ: Всегда используй строгую типизацию (type hints) в соответствии с Python 3.12+.
6. ПОДТВЕРЖДЕНИЕ УСПЕХА: После создания или успешного изменения файла, добавь в код короткий `print("SUCCESS: <описание действия>")` или выполни команду, которая выведет это в консоль. Это критически важно для автоматической проверки.
